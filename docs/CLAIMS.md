# Каноническая матрица научных утверждений

Машиночитаемый источник истины — [`research/claims.yaml`](../research/claims.yaml).
Формулировки синхронизированы с финальной рукописью v11.

| ID | Гипотеза v11 | Уровень | Статус | Краткий вывод |
|---|---|---|---|---|
| `H1-STRUCTURAL-DIAGNOSTICS` | H1 | дополнительный | подтверждено на проверенной подвыборке | HI-CSG-R пригоден для структурной диагностики, но не является полной топологической разметкой. |
| `H2-RELEVANT-DATA-AUGMENTATION` | H2 | основной | подтверждено | Релевантные дополнительные данные улучшают CRNN-CTC на трёх seed. |
| `H3-SELECTIVE-PREDICTION` | H3 | дополнительный | частично подтверждено | Confidence снижает CER при уменьшении покрытия; структурный вклад невелик. |
| `H4-GRAPH-FUSION` | H4 | поисковый | exploratory | Графовая ветвь содержит сигнал, но устойчивое преимущество не доказано. |
| `BOUNDARY-NATURAL-LINE-UNIQUENESS` | — | граница | не подтверждено | Эффект нельзя связывать исключительно с естественным строковым контекстом. |
| `BOUNDARY-PEN-TRAJECTORY` | — | граница | ложно по постановке | Граф не восстанавливает реальную траекторию пера. |

## Правило использования старых H1/H2/H3

До v11 обозначения H1–H3 менялись. Поэтому при ссылке на старый отчёт нужно
указывать не только номер, но и стабильный ID из таблицы либо явно писать
«historical H1/H2/H3». Новые документы используют только стабильные ID.
