# Synthetic smoke fixture

Этот пакет проверяет чтение изображения, manifest, скелетизацию и построение
графа без доступа к научным датасетам. Изображение создано специально для
тестов, не является образцом рукописи и не используется для оценки качества.

Smoke-test доказывает работоспособность интерфейсов, но не воспроизводит
обучение или статистические выводы статьи.
