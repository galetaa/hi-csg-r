# Архив реализации

`legacy_tools/` содержит все экспериментальные сценарии, ранее находившиеся в
корневом `tools/`. Ничего не было удалено: сохранены 189 tracked-файлов и все
локальные вспомогательные файлы, найденные во время переноса.

Контроль исходного Git tree перед переносом:

```text
HEAD:tools = db4cb3867cd812ce8820515303dc872d5a2e5e64
tracked files = 189
all local files before/after move = 377/377
SHA-256 list before/after = identical
```

Архивные скрипты могут содержать старые пути `tools/...` и старые импорты.
Для строгого воспроизведения используйте milestone tag соответствующего этапа.
Новый канонический интерфейс находится в `src/pipeline`.
